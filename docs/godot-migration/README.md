# RGFN: развитие на Godot + C#

Рабочая база от 12 октября 2026 года. Этот пакет фиксирует итог обсуждения
и организует дальнейшую работу небольшими шагами с человеческим ревью.
Сейчас создана документация; реализация нового проекта ещё не начата.

## Зафиксированный объём

- Цель: законченная уютная и увлекательная пошаговая RPG/roguelike для Steam.
- Рабочий стек: Godot + C#, с игровым ядром без зависимости от Godot.
- Один репозиторий для текущей и новой версии.
- Войны фракций, автономные конфликты и захваты деревень входят в первый релиз.
- Несколько актов и отдельная система переходов между ними — после первого релиза.
- Большую часть реализации делает агент; человек читает и ревьюит маленькие
  законченные изменения. Процесс и правила будут уточняться по результатам работы.

задачи; остальные документы читаются по затронутым границам. Не нужно каждый раз
перечитывать весь архив TypeScript-рефакторингов.

## Как поддерживать пакет

STATUS.md хранит фактический прогресс. ROADMAP.md хранит порядок и цели;
отметки выполнения не дублируются в нём. Карточки описывают условия задачи,
а результат и ревью записываются в STATUS.md.
Когда журнал вырастет, старые завершённые записи переносятся в history/YYYY-MM.md;
актуальная точка продолжения остаётся короткой.

Постоянное рабочее правило меняется в RULES.md. Архитектурное или продуктовое
решение меняется в DECISIONS.md и соответствующем разделе видения. Изменение
roadmap не означает, что перечисленный там код уже существует.
