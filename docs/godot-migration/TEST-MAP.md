### TURN-001: точная граница

Источник на момент выбора: commit 18cc253. Arrange: активный живой игрок,
затем активный мёртвый противник. Действие: инициализация ходов.

| Проверка TypeScript | Эквивалент NUnit |
| --- | --- |
| `assert.equal(tm.getCurrentEntity(), player)` | `Assert.That(manager.CurrentParticipant, Is.SameAs(player))` |
| `assert.equal(tm.isPlayerTurn(), true)` | `Assert.That(manager.IsPlayerTurn, Is.True)` |

`Is.SameAs` сохраняет проверку идентичности объекта, а не только равенства полей.
Обе проверки перенесены без ослабления. Игрок определяется явным ID вместо
сопоставления `constructor.name`. Координаты и данные отображения из исходной
фикстуры не нужны этому поведению и не входят в C#-тип.

В ядре реализована фильтрация активных живых участников и выбор первого.
TurnParticipant — минимальные данные для инициализации, не полноценный персонаж
или новый источник постоянного здоровья. Один тест не доказывает всех вариантов
фильтрации: мёртвый первым, неактивный первым и пустая очередь ещё не проверены.

**Весь исходный initializeTurns не считается перенесённым.** Его сброс ожидания
ввода, сброс пропусков ходов, распределение команд и остальные варианты состояния
пока отсутствуют в новой реализации. Другие методы также ещё не перенесены.

из-за успешной сборки.

## Поддержание карты

Добавлять одну строку на переносимый сценарий и необходимые пояснения
к утверждениям/изменённой границе. При изменении исходного теста сверять его
с прежним контрактом; при расширении покрываемой функции уточнять оставшиеся части.
Если для требования этапа исходного теста нет, явно указывать новый тест
по согласованному правилу или характеризующий тест существующего поведения.
