# Инструкции для агента RGFN

## Область работы

Этот репозиторий содержит текущую TypeScript-игру. Направление дальнейшей
разработки — Godot + C# в том же репозитории. План и рабочие правила находятся
в [docs/godot-migration/README.md](docs/godot-migration/README.md).

Для задач миграции, нового Godot-кода и изменения самого плана:

1. Прочитай индекс, [правила](docs/godot-migration/RULES.md),
   [процесс](docs/godot-migration/WORKFLOW.md) и
   [состояние работы](docs/godot-migration/STATUS.md).
2. Найди карточку назначенной задачи. Перед первым изменением соответствующей
   границы прочитай нужный раздел видения и структуры репозитория.
3. Работай одним маленьким проверяемым шагом. Не реализуй целый этап roadmap
   без явного поручения пользователя на такой объём.
4. Сохраняй результат, проверки, состояние ревью и следующий шаг в STATUS.md.
   Память чата не является единственным местом хранения этих сведений.
5. Новые указания пользователя внеси в актуальные правила или решения,
   если они меняют дальнейшую работу. Указания пользователя имеют приоритет
   над локальными документами; временные исключения отмечай с областью действия.

Первый релиз включает войны фракций и захваты деревень. Несколько актов
отложены до развития после первого релиза.

## Текущая TypeScript-версия

При её изменении учитывай CODING_GUIDELINES.md и актуальные документы системы.
Исторические инструкции с путём rgfn_game/ относятся к этому корню;
проверяй реальные команды по package.json. Сейчас используются npm run build
и npm test. Обсуждение новой архитектуры само по себе не разрешает перемещать,
переписывать или удалять существующие игровые файлы.

Не создавай коммиты, PR и публикации только ради отметки прогресса,
если это не входит в поручение. Завершённый локальный diff тоже является
проверяемым результатом.
